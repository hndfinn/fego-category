# Category SEO, layout and links

## Placement

- Use one meaningful H1 from the category template. No H1 inside the below-grid HTML block.
- Put a short category introduction in WooCommerce PRODUCT CATEGORY description above the product grid. This is taxonomy term description, not a product's short description.
- Below-grid block starts with the first H2 of the buying guide. Do not duplicate the intro. Preserve the theme's product grid, pagination and filters.
- Word Title can inform the page H1 but must not create another one; Word Heading 1 → web H2, Heading 2 → H3. Confirm the actual rendered hierarchy.

## Keyword scope

One category owns a broad shopping intent. Specific products own model/variant/material/size queries. Related categories retain their own intent. Map primary + genuinely relevant secondary terms to title, intro, a few headings and natural copy; do not force exact matches everywhere. Focus-keyword fields are editor hints, not direct Google ranking signals. No keyword-density quotas, score chasing, invented volumes or guarantees.

Title should describe the assortment and brand without unsupported prices, counts, best-seller labels or year bait. Meta description should summarize selection value; no rigid character-count rule or SERP display promise. Preserve slug unless explicitly requested. Check canonical, index directives, robots access, collection/breadcrumb schema and pagination. Page 2 should have appropriate self-canonical; do not casually canonicalize all pages to page 1.

## Contextual links

Use valid product/category URLs from evidence. Prefer one helpful contextual link per featured product in the editorial body; the product grid already links to products. Repetition can be legitimate, but must be justified by navigation value. Do not append a separate "Xem…" row to every paragraph. Link a descriptive product phrase within a caption or sentence. Preserve useful related-category links inline. Do not add nofollow to ordinary internal product links.

Links need a visible non-color cue: underline, sufficient contrast, hover and keyboard focus treatment. Keep unlinked caption text visually distinct. Scope CSS to the intended block/paragraph, never globally change unrelated site links. Verify the actual generated CSS and, where possible, rendered styles. Do not confuse CSS-source presence with browser verification.

## Media and writing QA

Use supplied WebP assets and proper rendered dimensions/srcset; optimize within image fidelity requirements. Generate images only for planned section slots in the category draft pass (or when otherwise requested); never redesign the product. Distinguish real gallery assets from generated context illustrations in provenance. Caption is visible text; alt describes the image, not a caption paragraph or keyword list. Decorative assets may use empty alt. Avoid changing shared attachment alt globally without considering other uses; create a scoped asset or use supported local alt if needed.

Original image total is not transferred-page weight; lazy loading and responsive candidates affect actual downloads. Do not assert Core Web Vitals or performance improvements without measurement. Long content is not inherently bad: remove repetition and vague filler based on user value, not arbitrary word count. Never add FAQ or fake reviews just to satisfy an SEO plugin.
